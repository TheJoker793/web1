# Exercice 3.3 : Conversions

## Énoncé

1. Écrire en HEX : `rgb(255,165,0)`.
2. Développer le raccourci `#f0c`.
3. Quelle couleur est `hsl(240,100%,50%)` ? Écrire son RGB.
4. Écrire en RGB : `#000000` et `#ffffff`.

## Réponse

```
rgb(255,165,0)   →  #ffa500  (ff=255, a5=165, 00=0)
#f0c              →  #ff00cc
hsl(240,100%,50%) →  bleu = rgb(0,0,255)
#000000 → rgb(0,0,0)   (noir)
#ffffff → rgb(255,255,255) (blanc)
```

## Remarque

Chaque paire de chiffres hexadécimaux va de 00 à ff, soit 0 à 255.
