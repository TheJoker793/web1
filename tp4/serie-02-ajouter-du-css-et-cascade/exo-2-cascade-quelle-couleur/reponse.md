# Exercice 2.2 : Cascade : quelle couleur ?

## Énoncé

1. Sans exécuter, donner la couleur finale du `h1`.
2. Que se passe-t-il si on inverse l'ordre des deux règles ?

## Réponse

```
h1{color:navy}
h1{color:orange}
```

## Remarque

**Orange** : à sélecteurs égaux, la dernière règle l'emporte. En inversant l'ordre, le titre serait bleu marine. Un style en ligne l'emporterait sur les deux.
