# Exercice 6.4 : Questions de cours

## Énoncé

1. Quelle valeur n'affiche des barres de défilement que lorsque c'est nécessaire ?
2. Quelle est la différence entre `scroll` et `auto` ?
3. Quelle propriété permet de gérer le défilement horizontal seulement ?

## Réponse

```
1) overflow: auto
2) scroll : barres toujours affichées ; auto : seulement si le contenu dépasse.
3) overflow-x (et overflow-y pour le vertical).
```
