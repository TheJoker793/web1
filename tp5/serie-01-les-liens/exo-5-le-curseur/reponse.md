# Exercice 1.5 : Le curseur

## Énoncé

1. Quelle propriété change le curseur de la souris ?
2. Quelle valeur pour : un élément cliquable ? un élément d'aide ? un traitement en cours ?

## Réponse

```
cursor: pointer;   /* élément cliquable (main) */
cursor: help;      /* aide */
cursor: wait;      /* attente / traitement en cours */
```

## Remarque

La propriété est `cursor`.
