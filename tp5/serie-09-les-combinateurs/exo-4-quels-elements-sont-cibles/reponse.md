# Exercice 9.4 : Quels éléments sont ciblés ?

## Énoncé

1. Avec la structure HTML fournie (P1 dans la div, P2 dans une section de la div, P3 et P4 après la div), indiquer les paragraphes ciblés par : `div p`, `div > p`, `div + p`, `div ~ p`.

## Réponse

```
div p     -> P1 et P2
div > p   -> P1
div + p   -> P3
div ~ p   -> P3 et P4
```
